资源错配的真正源头：论对“行业替罪羊”叙事的反思

发表于： 2026-09-23 分类于： 价值
字数： 1560 阅读：≈ 4分钟 浏览：

近年来，一种流行观点认为：

中国经济的结构性问题源于某一特定行业的过度膨胀

——尤其是房地产。

该观点主张，只要压缩甚至“出清”该行业，资本、人才与信贷资源便会自动流向科技、制造与消费领域，从而实现“腾笼换鸟”式的高质量发展。

这一逻辑常被形象地概括为：“一鲸落，万物生。”

然而，奥地利学派经济学提供了一个截然不同的视角：

问题不在于某个“鲸鱼”太大，

而在于那个永不破产、无限扩张的“制度巨兽”

——即缺乏有效约束的行政体系。

一、“鲸鱼”实为经济循环的枢纽

将房地产视为“吸血鬼”，是对现代经济复杂性的严重误读。

在真实世界中，房地产并非孤立存在，而是深度嵌入生产结构的关键节点：

它连接上游的钢铁、水泥、玻璃、家电；

它支撑中游的建筑、设计、物流、金融；

它吸纳下游的装修、家居、物业、社区服务；

它为地方政府提供公共服务所需的部分财政基础（尽管该模式本身亟待改革）。

当政策导向从“调控”滑向“压制”，整个产业链同步收缩：

→ 钢厂减产 → 矿工失业； → 家电滞销 → 渠道裁员； → 地产停摆 → 建筑工人返乡。

这不是“资源释放”，而是“系统性萎缩”。

资本并未流向芯片或新能源，而是因预期恶化而全面退潮

——因为企业家发现，连最基础的住房需求都被定义为“风险”，那么任何长期投资都变得不可预测。

二、真正的“资源黑洞”：无约束的行政成本

若真要追问“谁在吞噬资源”，答案不在市场，而在体制内部：

各级政府机构、事业单位、国有企业附属部门持续扩张，编制与预算刚性增长；

重复审批、多头监管、运动式执法消耗大量社会交易成本；

“智慧城市”“示范工程”等项目常以创新之名行套利之实，产出与投入严重失衡。

这些活动不创造可交易的价值，却消耗真实资源——土地、资金、人力、企业家的时间与精力。

更关键的是，它们无需面对市场检验：项目失败无问责，效率低下无淘汰，预算反而可能因“问题复杂”而增加。

相比之下，房地产企业若产品滞销，立即面临现金流断裂；

开发商若判断失误，终将破产退出。

市场中的“鲸”，终究受制于盈亏法则；

而体制内的“巨兽”，却享有事实上的无限责任豁免。

三、国际镜鉴：精简政府，方能激活市场

阿根廷总统米莱上任后，并未宣称“搞死某个行业”，而是直接裁撤9个中央部委，削减半数公务员编制，废除数百项行政许可。

结果如何？

通胀率显著回落；

外汇黑市溢价收窄；

私人投资信心回升；

财政赤字压力缓解。

其逻辑极为清晰：

不是把A行业的资源抢来给B行业，而是通过缩减政府自身规模，让整个经济系统的交易成本下降，从而释放所有行业的内生活力。

这印证了奥派的核心命题：繁荣不来自产业政策的“精准滴灌”，而来自制度环境的“普遍松绑”。

四、出路：从“行业整治”转向“制度减负”

与其争论哪个行业该“落”，不如聚焦如何让所有行业都能“生”：

大幅压缩非必要行政编制与财政供养人员，将公共资源真正用于公共服务；

全面清理隐性准入壁垒，让企业无论从事何种行业，都能自由进入、公平竞争；

将地方政府考核重心从“GDP增速”转向“制度成本指数”（如开办企业时间、合规费用、纠纷解决效率）；

推动财政体制改革，减少地方对土地出让金的依赖，从根源上化解房地产的“政策绑架”。

结语：不要寻找替罪羊，要拆除路障 中国经济的问题，从来不是某个行业“太大”，而是所有行业都背负着过重的制度成本。

当我们将矛头指向市场中的“鲸鱼”，实则是在转移对真正问题的注意力

——那个不断自我复制、自我赋权、却无需自负盈亏的行政体系。

真正的“万物生”，不始于某头鲸的死亡， 而始于所有企业家发现：

前方不再有路障，身后不再有追兵， 他们只需专注一件事——服务他人，创造价值。

那才是繁荣的起点。

本文基于奥地利学派对干预主义与自发秩序的分析框架，旨在探讨资源配置的制度成因，不针对任何具体行业或企业，亦不构成投资建议。

所有政策建议均以提升经济效率、降低社会交易成本为出发点。
