无人驾驶全球竞速，深圳出牌“萝卜快跑”

发表于： 2026-08-06 分类于： 价值
字数： 3654 阅读：≈ 8分钟 浏览：

在城市竞速的赛道上，以萝卜快跑为代表的中国头部无人驾驶力量，正在成为助力深圳夯实全球无人驾驶领先地位的核心力量。

撰文丨艾川

无人驾驶Robotaxi，正在成为全球产业与技术博弈的焦点赛道。

就在最近，修订后的《深圳经济特区智能网联汽车管理条例》正式施行，深圳也成为全国首个为无人驾驶明确制度的城市。《条例》中明确指出，市政府可以“在全市有序探索全域开放道路测试、示范应用，探索开展商业化运营试点”。

随后有消息称多家无人驾驶公司获得道路测试许可，将在深圳本地试点区域开展L4级Robotaxi实地测试。

与此同时，中国无人驾驶公司的出海步伐也在不断加速。近日，Uber和Lyft旗下欧洲出行平台Freenow相继宣布与百度旗下无人驾驶品牌萝卜快跑达成战略合作，在英国伦敦启动路测。

更早一些，萝卜快跑已经在香港正式开展全无人驾驶测试，实现了全球首次有企业在“右舵左行”市场实现车内无安全员驾驶。

▲Freenow与萝卜快跑合作，在伦敦启动路测

这意味着，无论从政策端还是企业端，中国Robotaxi产业都处于发力进行时。

此外，美国当地时间7月30日，美国国家公路交通安全管理局（NHTSA）宣布，向亚马逊旗下的Robotaxi品牌Zoox授予临时豁免，允许其在未来两年内每年商业部署最多2500辆专门设计的无人驾驶车辆。

更早一些，谷歌旗下Robotaxi品牌Waymo宣布将把无人驾驶服务扩展至四个新的美国城市：丹佛、圣迭戈、拉斯维加斯和坦帕。目前Waymo的无人驾驶已在旧金山、圣安东尼奥、奥兰多、菲尼克斯等多个美国大城市投入运营。

中美如此密集的消息和头部公司的动作变化，共同指向的是同一个信号：Robotaxi已经进入了大规模商用的最后冲刺期。

而从公司产品到城市产业的落地速度比拼，正在成为冲刺期博弈的核心所在。

01

Robotaxi：技术、产业加速进化

进入2026年，全球无人驾驶赛道最显著的特征莫过于“进化速度”的指数级提升。

如果说过去的五年是无人驾驶技术在实验室与小范围试点区域内的“萌芽期”，那么如今则正式迈入了跨区域、跨国界、超大规模商业化落地的“进化期”。

这首先体现在****技术进展上。

在这一轮全球化的加速度中，以萝卜快跑为代表的中国科技领军公司，正展现出前所未有的全球化布局野心与执行力。从中国内地的深圳，到中国香港的机场岛，再到欧洲核心枢纽伦敦，萝卜快跑的扩张很显然是一场高度战略协同的全球生态构建。

值得注意的是，无人驾驶目前在全球跨国落地的核心技术难点，并不是仅仅在于应对不同的语言界面或地图数据，而在于对“左舵（Left-Hand Drive, LHD）”与“右舵（Right-Hand Drive, RHD）”两种完全不同的驾驶规则体系与物理空间布局的无缝切换与深度适配。

在全球交通格局中，约70%的国家和地区采用左舵右行规则，而包括英国、中国香港、澳大利亚、日本、新加坡等在内的30%区域则坚持右舵左行规则。

对于传统的无人驾驶算法框架而言，从左舵系统切换至右舵系统，绝不是把方向盘换个边那么简单。在预测与决策规划层面，整套驾驶逻辑都要重写——路权归属、变道与让行的规则、车辆上下客的位置等交互逻辑都会发生变化，这对无人驾驶大模型的泛化能力提出了极苛刻的要求，而萝卜在香港的右舵市场，正是一次系统性的技术自证。

▲萝卜快跑在香港进行全球首个右舵全无人测试

再来看产业格局的加速。

放眼全球Robotaxi的竞争格局，尽管参与者众，但真正具备“大规模全无人商业化运营能力”并跻身第一梯队的，唯有中国的萝卜快跑与美国的Waymo。两大巨头在发展路径与产业高度上展现出了极高的相似性与互映性。

在运营规模上，截至目前，萝卜快跑与Waymo的全球累计无人驾驶出行服务订单量双双突破了2000万单大关。在行业权威评估机构与投行发布的数据榜单中，两者更是常年并列全球第一、第二名，以断崖式的领先优势将其他竞争对手甩在身后的“第一梯队”。

在商业模式上，Waymo与萝卜快跑也都完成了从带安全员的示范应用向真正全车无人化商业运营的跨越，并开始与 Uber、Lyft旗下的Freenow 等全球主流出行平台展开深度的 API 级合作，走向“技术平台+出行服务商”的深度共生形态。

总的来说，全球无人驾驶市场目前已然从技术和产业层面跨越了千舸争流的早期混沌，正式形成了清晰的双极格局：中美两国双雄对峙。

02

深圳VS洛杉矶：场景决定产业未来

但技术和产业，终究需要有落地的支点。

在Robotaxi从实验室走向规模化运营的过程中，选择哪座城市作为主战场，直接决定了技术的迭代速度与商业化的成败。而从全球范围来看，如果说Waymo选择的洛杉矶是西半球无人驾驶的理想试金石，那么深圳无疑拥有无可比拟的“落地主场优势”。

洛杉矶作为美国第二大都市圈，以其庞大的汽车保有量、错综复杂的高速公路网以及高度依赖私家车出行的城市结构，成为Waymo等美国无人驾驶巨头梦寐以求的商业高地。

洛杉矶的道路场景涵盖了从日落大道的拥堵路段到405号州际公路的高速汇流，从好莱坞山区的狭窄陡坡到圣莫尼卡海滩的密集人流，这种极具代表性的美式城市结构，的确能够极大锻炼无人驾驶系统的长尾场景处理能力。

▲洛杉矶街头的Waymo（图/视频截图）

当我们将视角转向东半球的深圳，就会发现深圳所具备的“落地主场优势”，在维度上更为多元，在生态上更为完整。

深圳作为中国人口密度最高、经济活动最活跃的超大城市之一，其城区道路交通复杂度堪称全球之最。在深圳，Robotaxi需要面对的不仅仅是标准化的机动车流，还有高密度的电动自行车混行、频繁的行人横穿、极为复杂的地下立交与多层立交桥网，以及华南地区多变的高温暴雨等恶劣天气。

**无人驾驶技术的成长，离不开真实交通场景的持续检验。**道路平缓、车流稀少的城郊环境，很难充分暴露行驶中的各类突发状况。而深圳路网错综复杂，出行场景多元，同等里程里可以遇到更多真实交互情景，倒逼系统持续优化决策能力，极大地加速了无人驾驶算法的磨合与进化。

然而，仅有复杂的物理场景不足以支撑技术落地。从算法进化到商业化应用，无人驾驶的跨越必须依托敢于先行先试的制度支撑。当技术磨合渐趋成熟，如何赋予车辆合法的“上路权”，成为全球城市面临的共同考题。

▲深圳市（图/CFP）

正是在这一节点上，深圳给出了极具示范效应的制度解法。2026年修订后的《深圳经济特区智能网联汽车管理条例》正式实施，标志着深圳在法规层面再次走在了全球前列。

与美国加州遭遇的州级监管与市级议会政策拉锯、工会抗议以及行政审批流程繁琐不同，深圳展现出了高度协调、敢为人先的制度优势。

深圳通过立法，不仅明确了无人驾驶车辆的事故责任认定、商业化收费许可，更在全市范围内率先探索“有序开放的道路测试”，打破了传统试点区域的“篱笆墙”。

这种政策的连续性、明确性与高效性，为无人驾驶企业提供了最宝贵的政策环境确定性预期。

03

萝卜快跑+深圳速度：智能产业新引擎

而我们从地缘再回归到产业视角来看，会发现这两者的进程正在互相影响。

在城市竞速的赛道上，以萝卜快跑为代表的中国头部无人驾驶力量，正在成为助力深圳夯实全球无人驾驶领先地位的核心力量。

**萝卜快跑与深圳的结合，是一场技术与城市的双向奔赴。**萝卜快跑将其最先进的第六代无人车、最新的大模型算法带到深圳。正是这种“深圳速度”与顶尖技术的深度融合，让深圳得以通过一张张亮眼的企业名片，向全球展示其作为“全球数字能源与智能网联汽车之都”的硬核实力。

▲深圳市（图/CFP）

今天的科技产业竞争，早已超越了单纯的技术与产品维度，而是直接关系到一座城市的综合竞争力与经济体在地缘博弈中的战略砝码。

当汽车产业全面迈入智能化、网联化与无人驾驶时代，其产业拉动效应更是呈现出几何级数的放大。无人驾驶不再只是一个移动交通工具，它集成了AI顶尖算法、车规级高性能计算芯片、实时空间感知、高精地图以及新能源动力系统，是“具身智能（Embodied AI）”在物理世界中最先实现商业化闭环的大规模落地形态。

一座城市如果在无人驾驶赛道上取得领先，就意味着同时占据了人工智能算法高地、高端智能制造高地以及未来智慧城市数据枢纽高地。

如今，当萝卜快跑的第六代无人车将整车成本大幅压缩至20万元以内，并在深圳这种高密度城市率先跑通商业闭环、走向盈利，无人驾驶便摆脱了依赖补贴与资本输血的阶段，转化为了能够大规模复制、产生巨额经济价值的实体产业。

通过在深圳这片热土上先行先试，一个由千万级城市居民每天真实使用、由数亿公里复杂路况数据滋养出的物理级智能产业生态系统正在加速形成。这是任何地缘政治手段都无法割裂或封锁的硬核产业牌。

未来，随着萝卜快跑带着在深圳验证成熟的“中国无人车方案”走向伦敦、香港乃至更广阔的全球市场，它输出的就已经不仅是一辆辆无人驾驶汽车，更是一整套关于未来城市交通运营的经过验证的完整经验和高度可行的方案。

在这一进程中，萝卜快跑的技术进化与深圳的城市速度相得益彰，共同铸就了中国在智能网联汽车时代领跑全球的硬核底气。
